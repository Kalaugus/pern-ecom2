# PERN E-Commerce

A full-stack e-commerce app built with PostgreSQL, Express, React, and Node.js.

**Status:** In progress. User login is working; product catalog and cart are next.

## Tech stack
- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** PostgreSQL

## Roadmap
- [x] User authentication
- [ ] Product catalog
- [ ] Shopping cart
- [ ] Checkout

## Running locally
1. Clone the repo
2. Run `npm install` in the backend folder
3. Set up your PostgreSQL connection in a `.env` file
4. Run `npm start`
